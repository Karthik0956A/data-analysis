# Week 4 – Comprehensive Data Science Report and Insights Presentation Plan

## Overview
This week consolidates all findings into a polished, executive-ready comprehensive report for the Customer Churn Prediction project.

## Folder Structure
```
Week4/
├── generate_diagrams.py   → Generates executive dashboard, insights, recommendation matrix
├── final_report.py        → Produces polished summary visualisations
├── generate_report.py     → Builds the final DOCX report
├── diagrams/              → Auto-generated PNG files
└── report/                → Output DOCX report
```

## How to Run
```bash
# From project root with venv activated:
cd Week4
python generate_diagrams.py
python final_report.py
python generate_report.py
```

## Deliverables
- `report/Week4_Final_Report.docx` — Executive-ready comprehensive final report
- `diagrams/executive_dashboard.png` — KPI summary dashboard
- `diagrams/insights_chart.png` — Feature importance and churn trends
- `diagrams/recommendation_matrix.png` — Impact vs. effort quadrant
- `diagrams/final_summary_plots.png` — Polished summary visualisations
