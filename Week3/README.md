# Week 3 – Python-Based Machine Learning Model Development and Evaluation Plan

## Overview
This week designs a detailed plan for developing and evaluating a machine learning model for Customer Churn Prediction using Python.

## Folder Structure
```
Week3/
├── generate_diagrams.py   → Generates ML workflow, model comparison, and evaluation diagrams
├── ml_pipeline.py         → Skeleton ML pipeline using scikit-learn
├── generate_report.py     → Builds the DOCX report with embedded diagrams
├── diagrams/              → Auto-generated PNG files
└── report/                → Output DOCX report
```

## How to Run
```bash
# From project root with venv activated:
cd Week3
python generate_diagrams.py
python ml_pipeline.py
python generate_report.py
```

## Deliverables
- `report/Week3_ML_Model_Plan.docx` — Full ML model plan document
- `diagrams/ml_workflow.png` — End-to-end ML pipeline workflow
- `diagrams/model_comparison.png` — Comparative model performance chart
- `diagrams/evaluation_metrics.png` — Evaluation metrics visual reference
- `diagrams/ml_pipeline_results.png` — Skeleton pipeline output chart
