# 📊 Data Science Internship Project – Customer Churn Prediction

A comprehensive 4-week data science internship project covering the full data science lifecycle for a **Customer Churn Prediction** problem in the Telecom domain.

---

## 🗂️ Project Structure

```
├── Week1/   → Project Planning & Strategy Design
├── Week2/   → EDA & Visualization Framework
├── Week3/   → ML Model Development & Evaluation Plan
├── Week4/   → Comprehensive Report & Insights Presentation
├── venv/    → Python virtual environment
└── requirements.txt
```

---

## ⚙️ Setup Instructions

### 1. Clone the repository
```bash
git clone https://github.com/username/data-science-internship.git
cd data-science-internship
```

### 2. Activate the virtual environment
```bash
# Windows
venv\Scripts\activate

# macOS/Linux
source venv/bin/activate
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

---

## 🚀 Running Each Week

Each week folder contains self-contained Python scripts:

```bash
# Week 1 – Generate diagrams and DOCX report
cd Week1
python generate_diagrams.py
python generate_report.py

# Week 2 – EDA framework + report
cd Week2
python generate_diagrams.py
python eda_framework.py
python generate_report.py

# Week 3 – ML pipeline + report
cd Week3
python generate_diagrams.py
python ml_pipeline.py
python generate_report.py

# Week 4 – Final insights + report
cd Week4
python generate_diagrams.py
python final_report.py
python generate_report.py
```

## 🎯 Project Theme: Customer Churn Prediction

**Problem**: Identify telecom customers likely to churn (cancel service) using historical usage and demographic data.

**Business Value**: Reducing churn by even 5% can increase profitability by 25–95% (Harvard Business Review).
