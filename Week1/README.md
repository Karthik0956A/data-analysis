# Week 1 – Data Science Project Planning and Strategy Design

## Overview
This week focuses on conceptualizing and strategically planning a data science project for **Customer Churn Prediction** in the telecom domain.

## Folder Structure
```
Week1/
├── generate_diagrams.py   → Generates PNG diagrams (lifecycle, Gantt, methodology)
├── generate_report.py     → Builds the DOCX report with embedded diagrams
├── diagrams/              → Auto-generated PNG files
└── report/                → Output DOCX report
```

## How to Run
```bash
# From project root with venv activated:
cd Week1
python generate_diagrams.py
python generate_report.py
```

## Deliverables
- `report/Week1_Project_Plan.docx` — Full project plan document
- `diagrams/project_lifecycle.png` — Data science lifecycle diagram
- `diagrams/timeline_gantt.png` — 30–35 hour project Gantt chart
- `diagrams/methodology_flowchart.png` — Strategy methodology flowchart
